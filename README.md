#  DeskPet-Reminder (像素桌宠防疲劳提醒系统)



​	一个基于 Godot 4 引擎开发的桌面宠物系统。本人人因工程课程的 Mini Project。DeskPet 会在屏幕边缘安静陪伴，并在你需要时，邀请你一起做个小休息。



## 功能

- **自定义番茄钟**：点击桌宠唤出面板，自由设定工作时长与休息时长。
- **休息提醒**：工作时间结束，桌宠会跳动并弹出气泡。30 秒无操作超时自动取消。
- **互动式休息引导**：内置关灯（暗屏）、眺望远方、起身走走等多种休息引导动画。
- **日志记录**：内置数据收集功能，一键导出带时间戳的本地日志（用于后续的人因数据分析）。



## 使用说明

- 程序运行依赖其所需dll，请勿随意移动文件位置

- 运行exe启动桌宠程序，长按桌宠拖拽移动。

- 鼠标悬停于人物上，点击冒出的气泡进入设置面板，可使用自定义工作/休息时间、导出日志等功能，点击开始工作按钮即可进入工作

- 气泡上的图案会根据状态显示不同的图案，默认状态为❓，进入工作状态显示💻，进入休息状态显示💤

- 在自定义时长中，默认时长为45min/15min，直接开始则以默认时长计时。

- 在工作模式或休息模式下，单击人物显示倒计时，可查看剩余工作/休息时间

- 工作时间结束后屏幕变暗、冒出气泡，提醒用户进入休息，若选择否则屏幕恢复、回到工作状态，重启工作倒计时

- 休息模式下可以通过与休息面板互动实现桌宠引导休息功能

- 休息时间结束后冒出气泡提醒用户进入工作，若选择否则重新进入休息模式。

- 对于提醒，无视超时都将回到待机状态，若要进入工作需要再次手动开启。

- ESC退出程序
